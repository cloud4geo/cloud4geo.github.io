SandBox OSM-US

Un entorno seguro para capacitar a nuevos mapeadores de OpenStreetMap.

El Desafío

OpenStreetMap US necesitaba una forma de capacitar a nuevos usuarios sin arriesgar vandalismo en la base de datos principal. Requerían una réplica aislada del stack de OSM.

Nuestra Solución

Desplegamos una réplica completa contenerizada de la API de OpenStreetMap y el stack de renderizado. Implementamos scripts automatizados para reiniciar la base de datos periódicamente.

Resultados Clave

  • Entorno seguro para 1000+ usuarios
  • Reinicios diarios automatizados
  • Experiencia idéntica al sitio principal de OSM
